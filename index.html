A simple beginning

Start with your
own little corner.

Snoozer runs as an operator-managed bot. The operator configures the bot and its Yapper permissions; each server can then be set up independently.

First / Invite01

Bring Snoozer in.

Join Snoozer Bot Central to find the community and current setup guidance.

Then / Configure02

Set your roles.

The server owner can set moderator and manager roles, then review server settings with /config.

Finally / Make it yours03

Choose what fits.

Review modules and permissions with your team, then enable the tools that suit your server.

Setup help, command guides, and known limits live in Docs.Snoozer depends on Yapper for permissions and platform actions.
