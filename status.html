Why might status be unavailable?

A public endpoint must be configured in assets/js/config.js as window.SNOOZER_STATUS_API_URL, be reachable over HTTPS, allow this site to read it, and return the documented JSON fields. Until then, this page cannot verify live status. See Docs: status endpoint.
