Start with the right detail.

For community support, visit the official Snoozer Bot Central Yapper server. No email support address or response-time commitment is provided here.

Getting started

Read the installation and invite notes, then check the role and permission guidance.

A command does not work

Check the command overview and the command's exact usage in the bot project's command reference.

Server settings

Use /config in the server in question. Snoozer settings and some community features are server-specific.

Status is unavailable

“Unable to verify” means the public endpoint is not configured, reachable, or returning the expected response. It does not mean the bot is offline.

When asking for help: describe what you were trying to do, the command name, which server context is relevant, and any non-sensitive error text. Never share bot tokens, populated configuration files, or private state files.

Yapper controls platform permissions and actions, so a command may also depend on the bot's Yapper role permissions and platform availability.
