# Snoozer Bot Central

The official monochrome landing page for the Snoozer community on Yapper.

- **Website:** https://truwty.github.io/Snoozer-Bot-Central/
- **Community:** https://yapper.website/invite/h4mQ4fJ6
- **Theme:** black and white, responsive, accessible, and dependency-free

This public repository contains only the website and the images it uses. The Snoozer bot source remains in a separate private repository.

GitHub Actions publishes the site automatically when changes are pushed to `main`. No build tools or external image services are required.
